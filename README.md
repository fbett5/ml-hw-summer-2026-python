# ml-hw-summer-2026-python
Module 4 homework: a simple Python program demonstrating user input and list search.
## Files

- `module4.py` — reads a positive integer N, then N numbers one by one, then a value X. Prints the 1-based index of the first occurrence of X, or -1 if X was not entered.

## How to run

    python module4.py

## Example

    Enter N (positive integer): 3
    Enter number 1: 5
    Enter number 2: 7
    Enter number 3: 9
    Enter X (integer): 7
    2
